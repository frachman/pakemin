# ADR-0008: Governance Positioning

- Status: Accepted
- Date: 2026-09-21
- Decision owners: Farandy Rachman

## Context

Pakemin was described as an AI Engineering Specification. That wording accurately reflects its origins but does not state how the portable core, agent authority, and deterministic verification fit together.

## Decision

Pakemin is an open-source AI Engineering Governance Framework. Its three pillars are Right Context, Clear Authority, and Verifiable Changes.

Pakemin remains local-first, Markdown-first, repository-native, and vendor-neutral. It is not an LLM wrapper, autonomous agent runtime, hosted memory service, MCP replacement, or vendor-specific orchestration platform.

## Consequences

Product documentation uses the governance category and explains the pillars through project-owned context, restrictive authority, and deterministic evidence. Historical ADRs may retain the earlier category when clearly identified as historical.

## Alternatives Considered

Keeping the previous category was rejected because it does not express authority or verification as first-class responsibilities.
