# Documentation

This directory contains the vendor-agnostic documentation for Pakemin, an AI Engineering Governance Framework for coding agents.

Current stable: `v0.1.2`. Target: `v0.2.0` (unreleased).

## Categories

- [Getting started](getting-started/README.md): introductory material for understanding the project and its philosophy.
- [Architecture](architecture/README.md): conceptual design of the portable core and vendor adapters.
- [Reference](reference/README.md): stable reference material such as repository structure.
- [Development](development/README.md): roadmap and documentation conventions for contributors.
- [Architecture decision records](adr/README.md): accepted architectural decisions and their consequences.

Start with [getting-started/overview.md](getting-started/overview.md) if you are new to the project.
