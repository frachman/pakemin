# Role Context

Status: Example
Owner: Farandy Rachman
Updated: 2026-08-02

## Maintainer

Maintainers own product direction, architecture decisions, release approval, and security-sensitive changes.

## Contributor

Contributors should keep changes small, update relevant `.ai` documents, and provide validation notes.

## AI Agent

AI agents should read `.ai/README.md`, load task-relevant context and rules, make scoped changes, and report validation clearly.
